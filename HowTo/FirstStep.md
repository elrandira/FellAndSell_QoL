# Environment install

## Binaries install

1. get [VSCode](https://code.visualstudio.com/docs/csharp/get-started)
1. once install, get C# Dev Kit extension from vscode extensions panel
1. install [.NET SDK](https://dotnet.microsoft.com/fr-fr/download) and check the install wih the command `dotnet --version`

## project creation 

- Go to the folder where all your projects are and run inside the command `dotnet new classlib -n FellAndSellQoL`. This will create the project with the folder
- edit the .csproj project file with the following:

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <TargetFramework>net6.0</TargetFramework>
    <!-- Change these two to your mod name -->
    <AssemblyName>FellAndSellQoL</AssemblyName>
    <RootNamespace>FellAndSellQoL</RootNamespace>
    <LangVersion>latest</LangVersion>
    <Nullable>disable</Nullable>
    <ImplicitUsings>disable</ImplicitUsings>
    <!-- Change this to your game folder -->
    <GameDir>C:\Program Files (x86)\Steam\steamapps\common\Fell and Sell</GameDir>
  </PropertyGroup>

  <ItemGroup>
    <!-- MelonLoader and Harmony (IL2CPP builds use the net6 folder) -->
    <Reference Include="MelonLoader">
      <HintPath>$(GameDir)\MelonLoader\net6\MelonLoader.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="0Harmony">
      <HintPath>$(GameDir)\MelonLoader\net6\0Harmony.dll</HintPath>
      <Private>false</Private>
    </Reference>

    <!-- Game assemblies generated by MelonLoader for IL2CPP -->
    <Reference Include="Il2Cppmscorlib">
      <HintPath>$(GameDir)\MelonLoader\Il2CppAssemblies\Il2Cppmscorlib.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="UnityEngine">
      <HintPath>$(GameDir)\MelonLoader\Il2CppAssemblies\UnityEngine.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="UnityEngine.CoreModule">
      <HintPath>$(GameDir)\MelonLoader\Il2CppAssemblies\UnityEngine.CoreModule.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="Il2CppInterop.Runtime">
      <HintPath>$(GameDir)\MelonLoader\net6\Il2CppInterop.Runtime.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="Assembly-CSharp">
      <HintPath>$(GameDir)\MelonLoader\Il2CppAssemblies\Assembly-CSharp.dll</HintPath>
      <Private>false</Private>
    </Reference>
  </ItemGroup>

  <!-- Copy the built DLL into the game's Mods folder after each build -->
  <Target Name="CopyToMods" AfterTargets="Build">
    <Copy SourceFiles="$(TargetPath)" DestinationFolder="$(GameDir)\Mods" />
  </Target>

</Project>
```

- create `QolMelon.cs`

```csharp
using MelonLoader;

[assembly: MelonInfo(typeof(FellAndSellQoL.QoLMod), "Fell & Sell QoL", "1.0.0", "YourName")]
[assembly: MelonGame(null, "Fell and Sell")]

namespace FellAndSellQoL
{
    public class QoLMod : MelonMod
    {
        public override void OnInitializeMelon()
        {
            MelonLogger.Msg("Fell & Sell QoL loaded!");
        }
    }
}
```

Notes:
- **Check the file names**. Open MelonLoader\Il2CppAssemblies\ and MelonLoader\net6\ and confirm each HintPath matches. Names differ between MelonLoader versions.
- **The Il2CppAssemblies folder may be empty**. MelonLoader generates these DLLs the first time you run the game with MelonLoader installed. Launch the game once, close it, and then build.
- **Only reference what you use**. If you don't use Il2Cppmscorlib or Il2CppInterop.Runtime, you can remove those lines, but keep MelonLoader and 0Harmony.
- **Use the same file name everywhere**. Earlier I named the file FellAndSellQoL.csproj. If you want the name FellAndSell_QoL.csproj, that's fine, but the project name and the .csproj name should match your folder structure.
- **IL2CPP restrictions**. Classes that inherit from Unity types, such as MonoBehaviour, must be registered with ClassInjector.RegisterTypeInIl2Cpp<T>() before use. Calls into Unity or game code are also handled through the generated wrappers, so the code is written against the same types you see in Il2CppAssemblies.

## Installing MelonLoader

- download and install [MelonLoader](https://github.com/lavagang/melonloader)
- run it, pick your game
- check in the game folder there are `MelonLoader`, `Mods` and `Plugins` folder

## Build and Test

- Press Ctrl+Shift+B in VS Code, or run `dotnet build -c Release` in the terminal.
- The DLL is copied to the game's `Mods` folder.
- Launch the game and look for "Fell & Sell QoL loaded!" in the MelonLoader console.
